BKNY Brawler Architecture

How an open source browser beat 'em up runs online co-op for 1 to 4 players on Docker, Kubernetes and Agones, with Xbox controllers.

The system at a glance

Each match runs in its own pod. Players reach it through a small gateway, because an HTTPS page can only open secure sockets and game nodes don't have certificates.

flowchart LR
  subgraph B[Browser]
    P[Xbox controller] --> C[Client: prediction and render]
  end
  C -- HTTPS and WSS --> I[Ingress with TLS]
  subgraph K[Kubernetes]
    I -- static files --> W[Client pods]
    I -- rooms and sockets --> E[Edge pods, stateless]
    E -- allocate room --> A[Agones controller]
    A -- manages --> F
    subgraph F[Agones Fleet]
      G1[Match pod]
      G2[Match pod]
      G3[Warm Ready pod]
    end
    E -- signed ticket only --> G1
    E -- signed ticket only --> G2
  end

How a match starts and ends

sequenceDiagram
  participant C as Browser
  participant E as Edge
  participant K as Agones
  participant G as Match pod
  C->>E: Create room
  E->>K: GameServerAllocation
  K-->>E: Allocated pod
  E-->>C: Room code and 60s ticket
  C->>E: Open WSS with ticket
  E->>G: Forward socket
  G-->>C: Full world snapshot
  loop Every tick at 60Hz
    C->>G: Input for a future tick
    G-->>C: Confirmed inputs, 30 sends a second
  end
  G->>K: Shutdown after the match
  K->>K: Replace pod from Fleet

Five decisions that shape it

QuestionChoiceReason
Who owns the truth?A dedicated serverNobody can cheat as host, and one player leaving doesn't end the match.
What goes over the wire?Inputs, ordered by the serverEvery peer runs the same integer simulation, so bandwidth stays tiny.
How does it feel instant?Local prediction with replayYour punch lands on the frame you press it, and server data corrects the rest.
How does it scale?One Agones pod per matchA crash affects one match. A buffer of Ready pods keeps room creation fast.
Which browser transport?WebSocket for nowWebTransport is Baseline, but Node has no built-in server and the whole path needs HTTP/3.

Xbox controller in the browser

The Gamepad API needs no plugin. Pair the controller, open the page, and press a button, because browsers hide pads until one is used. Poll navigator.getGamepads() every frame.

ActionXbox controlStandard index
MoveLeft stick or D-padAxes 0 and 1, buttons 12 to 15
AttackX or YButtons 2 and 3
JumpAButton 0
SpecialB, RB or RTButtons 1, 5 and 7
Join local playMenuButton 9

Rumble uses vibrationActuator.playEffect("dual-rumble"). It isn't available in every browser, so the game treats it as optional.
