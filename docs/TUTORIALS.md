# Tutorials and references

## Building a beat 'em up

- [Phaser 4 pirate beat 'em up](https://phaser.io/news/2026/06/vibe-code-a-complete-2d-beat-em-up-game-with-phaser-and-codex): a full build covering enemy AI, hitbox overlays, screen shake and hit pauses. [Source and written guide](https://www.vibegamedev.com/pirate-beat-em-up-resources), [video](https://www.youtube.com/watch?v=NwKZOn3O5oI).
- [10-hour Godot beat 'em up series](https://gamedev.net/forums/topic/717970-tutorial-on-creating-a-beat-em-up-game-in-godot-in-10h-beginnerintermediate): announced on GameDev.net. The page blocked automated reading, so I haven't reviewed it.
- [Godot beat 'em up demo](https://github.com/yockgen/godot-tut01): small open source example, built for Godot 3.
- [Finite state machines in Godot 4](https://gdquest.com/tutorial/godot/design-patterns/finite-state-machine/): the pattern behind fighter behavior.
- [2.5D beat 'em up discussion](https://www.html5gamedevs.com/topic/23371-25d-beat-em-up-where-to-start/): an old Phaser thread on sorting sprites by depth.

## Netcode

- [Deterministic Lockstep](https://gafferongames.com/post/deterministic_lockstep/): Gaffer on Games on why sending inputs works, and what it costs.
- [GGPO](https://github.com/pond3r/ggpo): the original rollback SDK.
- [GGRS](https://github.com/loganmc10/ggrs): rollback in Rust, with browser demos over WebRTC.
